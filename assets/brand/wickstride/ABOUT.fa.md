# هویت پیشنهادی WICKSTRIDE

نام: **Wickstride — ویک‌استراید**

Wick به فتیلهٔ کندل و Stride به گام و حرکت اشاره می‌کند. نام پیشنهادی برای هویت مستقل بازی است؛ نام فعلی سایت و شناسه‌های بازی تغییر نکرده‌اند.

شعار اصلی: **RUN YOUR LINE.**

برگردان پیشنهادی فارسی: **مسیرت را خودت بساز.**

توصیف کوتاه: **A free browser parkour game above a candlestick skyline.**

## نام‌های بررسی‌شده

| نام | جمع‌بندی |
|---|---|
| Wickstride | پیشنهاد اصلی؛ ترکیب مفهوم کندل و حرکت، مناسب یک برند مستقل |
| Chartstride | گزینهٔ توصیفی‌تر؛ ارتباط مستقیم‌تر با نمودار، ولی شخصیت کمتر |
| Chart Parkour | نام فعلی؛ برای توضیح ژانر زیر نام جدید همچنان کاربرد دارد |

Wickbound کنار گذاشته شد، چون بازی‌هایی با همین نام وجود دارند؛ یک نمونهٔ مستقیم: [wickbound.com](https://wickbound.com/).

جست‌وجوی مقدماتی وب، تأیید ثبت علامت، مالکیت نام، آزادبودن دامنه یا شناسهٔ شبکه‌های اجتماعی نیست. هیچ دامنه یا شناسه‌ای خریداری یا ثبت نشده است.

## لوگو

نشان W زاویه‌دار با دو امتداد کوتاه شبیه فتیلهٔ کندل طراحی شده است. بریدگی‌های پایین، ریتم گام و فاصلهٔ بین سکوها را تداعی می‌کنند. نشان بدون قاب هم قابل استفاده است؛ آواتار زمینهٔ تیره دارد.

- `logo-*.svg`: لوگوی افقی، کاملاً برداری و دارای حروف تبدیل‌شده به مسیر؛ نیازمند نصب فونت نیست.
- `wordmark-*.svg`: نام نوشتاری بدون نشان.
- `mark-*.svg`: نشان تنها، مناسب رابط بازی و آیکن.
- نسخه‌های `lime`، `white` و `dark` برای زمینهٔ مناسب ارائه شده‌اند.
- PNGهای لوگو و نشان شفاف‌اند؛ `avatar.png` زمینهٔ تیره دارد.
- `favicon.svg/png`: نسخهٔ ۶۴ پیکسلی.

در اطراف لوگو حداقل نصف ارتفاع نشان فضای خالی نگه دارید. نشان زیر ۲۴ پیکسل و لوگوی کامل زیر عرض ۱۶۰ پیکسل توصیه نمی‌شود. لوگو را نکشید، سایه و دورخط اضافه نکنید و روی صورت کاراکتر یا زمینهٔ شلوغ نگذارید.

## رنگ‌ها

| نقش | کد |
|---|---|
| زمینهٔ اصلی | `#0B1018` |
| نوشتهٔ روشن | `#EDF3F5` |
| حرکت و هویت اصلی | `#D9F66F` |
| حرکت ثانویه و سکوها | `#81E9DB` |
| خطر و کندل قرمز | `#FF7878` |

رنگ خطر، تزئین اصلی لوگو نیست. نسخهٔ روشن یا لیمویی روی زمینهٔ تیره و نسخهٔ تیره روی زمینهٔ روشن استفاده شود.

## بنرهای آماده

| فایل | اندازه | کاربرد |
|---|---|---|
| `banner-x-1500x500.png` | ۱۵۰۰×۵۰۰ | هدر شبکهٔ اجتماعی، تصویرسازی با کاراکترهای واقعی بازی |
| `banner-type-1500x500.png` | ۱۵۰۰×۵۰۰ | نسخهٔ خلوت با تمرکز بر نام و شعار |
| `banner-hero-1920x1080.png` | ۱۹۲۰×۱۰۸۰ | معرفی بازی و انتشار افقی |
| `brand-board.png` | ۱۲۰۰×۱۳۱۰ | نمای کلی هویت، لوگو، رنگ‌ها و نمونهٔ بنر |

عناصر اصلی بنر افقی از پایینِ چپ فاصله گرفته‌اند، اما پیش از انتشار باید پیش‌نمایش برش همان پلتفرم بررسی شود؛ این طرح، قالب ویرایش‌پذیر است و تأیید همهٔ برش‌های پلتفرم‌ها محسوب نمی‌شود.

فایل‌های HTML بنرها نیز موجودند و تصاویرشان درون فایل قرار دارند. برای ویرایش متن و جای‌گذاری می‌توان آن‌ها را باز کرد. لوگوی SVG مستقل از فونت است؛ متن بنر HTML از Bahnschrift با جایگزین‌های سیستمی استفاده می‌کند، بنابراین برای انتشار با ظاهر دقیق، PNG آماده مناسب‌تر است. فونت نصب‌شدهٔ سیستم در بسته توزیع نشده است.

کاراکترها و سکوها از مدل‌های واقعی پروژه برای این ترکیب تبلیغاتی رندر شده‌اند؛ تصویر بنر اسکرین‌شات مستقیم گیم‌پلی نیست. فایل `skyline-art.png` زمینهٔ شفاف دارد و برای ترکیب‌های بعدی قابل استفاده است.
